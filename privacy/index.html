Политика конфиденциальности

Дата вступления в силу: 26.08.2026

1. Общие положения

Настоящая Политика конфиденциальности описывает, какие данные обрабатываются при посещении сайта theХистори (thehistory.pro). Сайт — некоммерческий информационный проект, посвящённый истории; он не собирает данные пользователей через формы, не требует регистрации и не имеет личного кабинета.

2. Какие данные обрабатываются

Сайт сам по себе не устанавливает файлы cookie и не хранит персональные данные. Однако при заходе на сайт технические данные (IP-адрес, тип браузера, дата и время запроса, реферер) могут автоматически обрабатываться:

  • хостинг-платформой GitHub Pages, на которой размещён сайт;
  • сторонним CDN cdnjs.cloudflare.com, откуда подгружаются шрифты, иконки и библиотеки (Swiper, Ionicons).

Эти данные обрабатываются исключительно в технических целях (обеспечение работы и безопасности сайта) на стороне указанных сервисов и не передаются владельцу сайта напрямую.

3. Cookies

Сайт не использует собственные cookies. Сторонние сервисы (см. п. 2) могут использовать технические cookies в рамках своей работы — их обработка регулируется политиками соответствующих сервисов (GitHub, Cloudflare).

4. Внешние ссылки

На сайте есть ссылки на сторонние ресурсы, например Telegram-канал @historyflow. Владелец сайта не несёт ответственности за политику конфиденциальности сторонних ресурсов — рекомендуем ознакомиться с ней отдельно при переходе.

5. Права пользователя

Поскольку сайт не собирает и не хранит персональные данные пользователей самостоятельно, специальных запросов на удаление или изменение данных не требуется. По любым вопросам можно обратиться по контактам ниже.

6. Изменения политики

Политика может обновляться. Актуальная версия всегда доступна по этой ссылке в футере сайта.
